# PocketBuddy

## Description
PocketBuddy is a personal finance management system that helps users track their expenses, set and manage financial goals, handle subscriptions, and analyze spending habits. The system provides a user-friendly interface with charts and reports for better budgeting.

---

## Features
- Add, view, and manage expenses
- Set and track financial goals
- Manage subscription payments
- Donation tracking
- Generate budget charts and reports
- User login and profile management

---

## Installation / Setup
1. Copy the **PocketBuddy** project folder to your **XAMPP/htdocs** directory.
2. Open **phpMyAdmin** and import the database file `pocketbuddy.sql`.
3. Start **XAMPP Apache** and **MySQL** services.
4. Open your browser and navigate to:  
(http://localhost/pocketbuddy/index.php)

5. Login or register a new account to start using the application.
